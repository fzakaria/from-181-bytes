On i686-linux, nixpkgs builds GCC 16.2.0 from source. The one program it does not build is below: 181 bytes that turn hex text into bytes. Point at a byte to see its line of source.

Which nixpkgs grows from this

      

        Since
        nixpkgs#479322
        (January 2026), the standard environment on i686-linux and
        x86_64-linux starts from this chain:
        stage0.nix
        takes its last GCC and glibc. x86_64 starts from a 229 byte AMD64 seed.
        Other Linux platforms start from a prebuilt
        bootstrap-tools tarball.
      

      

        You still trust the kernel, the Nix daemon and the hardware.
        builder-hex0 and
        live-bootstrap
        remove the kernel too.
